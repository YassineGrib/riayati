Shared-widget golden references
==============================

`shared_widgets_test.dart` creates 20 snapshots: ten widget samples, each in
light and dark, at 360 × 800 logical pixels. The samples load the embedded
Thmanyah, IBM Plex Arabic and Material Icons fonts. Loading indicators are
captured after a fixed 200 ms frame; these tests deliberately do not settle
indeterminate animations.

Run from `03-app/mobile`:

```
flutter analyze
flutter test --update-goldens
flutter test
```

PNG baselines must be generated by the orchestrator: Flutter commands cannot
run in the implementation sandbox. Formatting has run; analyzer and test
results, and rendered golden comparison, are pending.

Design reference mapping (under `02-design/figcraft/output/`, both themes):

| Widget | Reference PNG stem |
| --- | --- |
| RButton | 02-Auth_Login; 03-Home_Home for secondary/SOS colors |
| RTextField | 02-Auth_Login; 02-Auth_Login-error |
| RCard | 03-Home_Home; 04-Reports_Reports-list |
| StatusChip | 03-Home_Home; 04-Reports_Reports-list |
| Watermark | 02-Auth_Login; 03-Home_Home; 04-Reports_Reports-empty |

| AppScaffold | 04-Reports_Reports-empty; 04-Reports_Reports-list |
| EmptyView | 04-Reports_Reports-empty |
| ErrorView | 02-Auth_Login-error feedback colors; empty-state composition |
| LoadingView | Auth/Home primary and secondary-text tokens; no dedicated design |

Measurements also follow `02-design/components.css`, `02-design/app.css` and
the empty-state rules in `02-design/reports-profile/index.html`: 56 dp controls,
12 dp control radii, 16 dp card radii/padding, 28 dp badges, 64 dp nav, and
24 dp content insets. Interactive targets are at least 48 dp. Controls grow
with wrapped text or larger accessibility text.

Intentional differences requiring review once goldens are rendered:

- Material Icons replace the boards' outlined SVG icons, as requested.
- Navigation uses the requested order (home, reports, calendar, assistant,
  account) and label التقارير, while the boards place reports fourth and use
  بلاغاتي.
- Navigation elevation uses the existing RShadow.xl token. No existing shadow
  token exactly reproduces the CSS's 8 px / 24 px shadow.
- RTextField's interface has no icon or password-visibility-toggle parameter.
  Its label, control, validation and helper typography follow the references.
- EmptyView's action uses the shared full-width button; the report board uses
  an intrinsic-width action.
- RButton's SOS variant uses the shared control silhouette. The larger Home
  CTA's subtitle, circular badge and chevron require screen-level composition.
- Colors use the protected generated semantic tokens, including SOS, rather
  than overriding any differences between token values and PNG exports.
