# End-to-end test report, 2026-11-20

Environment: Android emulator, debug build against the local Laravel server (`127.0.0.1:8765` through `adb reverse`), Filament admin in the in-app browser. Test accounts come from `database/seeders/E2eAccountsSeeder.php` (local only, never run in production).

## Worked
- Login as father and mother; the father's invite code linked the mother (the app shows "مرتبط بالأب").
- "تخطي الآن" on the link screen; Home opens, calendar card asks to link.
- Home: SOS card and the two shortcut cards.
- Library: list, type chips, detail. Centers: list, kind chips, wilaya filter, detail, call and copy buttons.
- New report with a photo (compressed to 143 KB), sent as RIA-2026-0143, listed under "بلاغاتي", detail screen, PDF opens (Arabic text correct, the photo on page 2).
- Calendar: the mother proposed a visit (25 Nov, 10:00-12:00), the father saw it and accepted; status "تم القبول".
- Admin: the report appears with reporter, attachment tile and timeline; "تمت المراجعة" asks for confirmation and works; the activity log recorded `report.reviewed`; visits list shows the accepted visit.

## Bugs found (to fix)
1. Report summary screen (after sending): "العودة للرئيسية" does nothing (system back works); the PDF card is not tappable.
2. Home still shows "no reports" right after sending one; it refreshes only after restarting the app.
3. Reports list says "بدون مرفقات" for a report that has one attachment (detail says one).
4. Digits mix in right-to-left text: date field of the new report, summary screen, Home card (`٢٠٢٦ · ١٠:٣٤` garbled); attachment name and size show as `jpg.53` and `KB 143`.
5. Summary screen shows 10:34 while the list, detail, PDF and admin show 11:34 (time zone).
6. Visit form: date and time are plain text (YYYY-MM-DD, HH:mm) although the icons suggest pickers; `1000` is rejected, which is correct but unfriendly.
7. Center detail: phone and working hours order is slightly off in the RTL layout; address "غير محدد" for placeholder data.
8. Skipping the link is forgotten when the app is fully closed (shown again next start).
