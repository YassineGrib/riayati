# thmanyah font family (local use only)

Source: https://font.thmanyah.com (the only place the license allows downloading from).
License: `LICENSE.pdf` (the Arabic text prevails). Contact for exceptions: ask@thmanyah.com.

## Do not distribute these files
The license forbids redistributing, sharing, uploading or hosting the font files, and forbids
making them available so third parties can extract them as font files (web embedding included).
It allows embedding in a mobile app only as part of a compiled/packaged product.

So, when delivering the project (ZIP, CD for ONDA, repository, handover):
- Do NOT include this folder. The client downloads the font herself from font.thmanyah.com.
- Do NOT serve these files from a website (landing page, Filament admin). Use another font there,
  or get written permission from ask@thmanyah.com first.

## Roles in Riayati
| Family | Use |
|---|---|
| thmanyah sans (Light, Regular, Medium, Bold, Black) | App UI: labels, buttons, fields, numbers ("digital" face) |
| thmanyah serif display | Large titles and the wordmark only |
| thmanyah serif text | Long reading text, e.g. legal articles |

## Typesetting rules from the official guide
- Kashida (extended letter forms) only between the last letter and the one before it; never in long text.
- Swash / stylistic alternates: never many in one sentence, never in two adjacent words, never in UI text.
- Long text uses the Text face, headlines use the Display face, digital surfaces use the Sans face.
